# SplitPad: игра вдвоём на одном ПК (Forge 1.20.1)

Мод добавляет в Minecraft управление с геймпада (DualShock 4, DualSense, Xbox и
другие) и сам раскладывает окно игры на свою часть экрана. Чтобы играть вдвоём,
запускаются **две копии игры**: одна занимает левую половину монитора, другая
правую. Каждая копия слушает только свой геймпад.

> Minecraft Java может показывать только одного игрока на окно, поэтому
> разделённый экран здесь собран из двух окон. Один игрок открывает мир для
> сети (LAN), второй к нему подключается.

## Что умеет

- Ходьба, камера, прыжок, удар и копание, установка блоков, хотбар, инвентарь,
  пауза. Кнопки настраиваются, на них можно повесить любую клавишу из
  управления, в том числе клавиши других модов (например, перезарядку в TACZ).
- Курсор в меню и инвентаре: двигается левым стиком, крестиком берёшь
  предмет, квадратом кладёшь по одному, треугольником переносишь весь стак
  (как Shift+клик).
- Игра продолжает работать, когда её окно не в фокусе. Поэтому оба игрока
  могут играть одновременно, и щёлкать по окнам не нужно.
- Само раскладывает окна: левая/правая половина, верх/низ или четверти
  экрана (до четырёх игроков). Окна без рамки.
- Мод только клиентский, на сервер его ставить не нужно.

## Установка для игры вдвоём

1. **Сделай две копии папки игры** со сборкой, например `.minecraft-p1` и
   `.minecraft-p2`. В лаунчере создай два профиля (TLauncher: «Настройки
   версии», а затем «Папка игры»), каждый со своей папкой. В обе папки
   положи `splitpad-1.0.0.jar` в `mods/`.
2. В каждом профиле добавь **аргументы JVM**:
   - игрок 1: `-Dsplitpad.screen=LEFT -Dsplitpad.gamepad=1`
   - игрок 2: `-Dsplitpad.screen=RIGHT -Dsplitpad.gamepad=2`

   Если игрок 1 играет на клавиатуре и мыши, поставь ему `-Dsplitpad.gamepad=0`,
   а второму `-Dsplitpad.gamepad=1`.
   Вместо аргументов можно настроить `config/splitpad-client.toml` в каждой
   папке: параметры `gamepad` и `screen`.
3. **Ники должны быть разными**, иначе второго игрока выкинет с сервера.
4. **Dynamic FPS** (`dynamic-fps-*.jar` есть в сборке) снижает FPS в окне без
   фокуса, и у второго игрока картинка почти замрёт. Есть два выхода: удалить
   этот мод из обеих копий или открыть его настройки и для режима «Unfocused»
   (окно без фокуса) поставить обычный FPS.
5. Запусти оба профиля. Игрок 1 создаёт мир, жмёт «Пауза → Открыть для сети» и
   разрешает читы, если они нужны. Игрок 2 заходит через «Сетевая игра»: мир
   появится в списке LAN.

**Память.** Сборка тяжёлая (TACZ, Superb Warfare и т. д.). Каждой копии нужно
4–6 ГБ (`-Xmx6G`), а всего в компьютере желательно 16 ГБ ОЗУ и больше.

## Если геймпад не работает

- Слева вверху игра пишет, какой геймпад нашла, а если не нашла, пишет это
  красным. В `logs/latest.log` есть строки `SplitPad: joystick ...` со
  списком всех подключённых контроллеров.
- Порядок геймпадов (1, 2, ...) совпадает с порядком подключения. Если игроки
  перепутались, поменяй цифры местами.
- Если Windows видит DualShock или DualSense, а игра нет:
  - установи [DS4Windows](https://github.com/Ryochan7/DS4Windows): он
    показывает геймпад PlayStation как геймпад Xbox, и тогда тот точно
    работает;
  - или скачай свежий
    [gamecontrollerdb.txt](https://github.com/mdqinc/SDL_GameControllerDB/blob/master/gamecontrollerdb.txt)
    и положи его в `config/splitpad/gamecontrollerdb.txt`.
- Steam при запуске игры может перехватывать геймпад. Если кнопки работают
  странно, отключи Steam Input для PlayStation-контроллеров.

## Настройки (`config/splitpad-client.toml`)

- `gamepad`: номер геймпада (0 значит без геймпада).
- `deadzone`, `lookSpeedX`, `lookSpeedY`, `invertY`, `cursorSpeed`: мёртвая
  зона стиков, скорость камеры, инверсия и скорость курсора.
- `bindings`: кнопки в игре. Формат `КНОПКА=действие`. Действие задаётся id
  клавиши (`key.jump`, `key.attack`, …; id клавиш модов есть в `options.txt`:
  строка `key_key.jump:...` означает `key.jump`) или одним из специальных
  действий: `splitpad:hotbar_next`, `splitpad:hotbar_prev`, `splitpad:pause`,
  `splitpad:toggle_sneak`.
- `menuBindings`: кнопки в меню (`left_click`, `right_click`, `quick_move`,
  `back`, `scroll_up`, `scroll_down`).
- `screen`: часть экрана (`FULL`, `LEFT`, `RIGHT`, `TOP`, `BOTTOM`,
  `TOP_LEFT`, `TOP_RIGHT`, `BOTTOM_LEFT`, `BOTTOM_RIGHT`).
- `monitor`: номер монитора.
- `borderless`: окно без рамки.
- `noPauseOnLostFocus`: не ставить игру на паузу, когда окно теряет фокус.

## Ограничения

- Чат и ввод текста только с клавиатуры. Чтобы написать в чат, щёлкни по
  своему окну.
- Нет вибрации и подсветки геймпада.
- Курсор в меню двигается только стиком, D-pad его не двигает.

## Сборка из исходников

```
./gradlew build
```

Готовый jar появится в `build/libs/`. Нужна Java 17 или новее.
